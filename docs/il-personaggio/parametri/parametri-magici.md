# Parametri Magici

I Parametri Magici sono:

- **Acume**
- **Empatia**
- **Percezione**
- **Potenza**
- **Tecnica**
- **Volontà**

## Parametri Magici e Categorie Magiche

Nel Regolamento le **Categorie Magiche** hanno valenza ONGame e intervengono nella distribuzione iniziale dei Parametri Magici. Ogni Categoria è associata a un Parametro peculiare:

| Categoria Magica | Parametro Magico |
| --- | --- |
| Acumen | Acume |
| Animus | Empatia |
| Ars | Tecnica |
| Numen | Potenza |
| Sensus | Percezione |
| Voluntas | Volontà |

La pagina definitiva conterrà anche tutte le regole attuali su guadagno, perdita, recupero e uso dei singoli Parametri.
