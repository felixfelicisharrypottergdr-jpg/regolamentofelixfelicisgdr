# Ricerca Casuale di Accordi

La **Ricerca Casuale di Accordi** è il sistema indicato dal regolamento per **PG Diplomatici**, con le aperture previste dalla fonte per altri PG in supporto.

> Estratto di prototipo: requisiti, fasi, dadi, esiti e premi saranno migrati integralmente senza essere ricostruiti per analogia con le altre Ricerche.
